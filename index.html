How many clips, and how long

          

            
            
            
          

          
Make all clips picks that many random clips from every ticked video, each with its own random length between Shortest and Longest, then records them one after another. Leave Longest empty to allow up to the whole video. These settings apply to every ticked video in the list above; untick a video to leave it out.

          
          

          
Starting value for every new clip’s own Audio sync control (under each clip). Raise if sound comes before the picture. Used by the normal recorder only (the fast engine is always exact). Tap Calibrate to measure it on this device: it records a 3-second test clip and listens to it. Each clip can still be adjusted separately.

          

          
          

            
            
            
            
          

          

          
Picks start at random places across the whole video and may overlap. Each press gives a new set.

        

        

          
Text lines for the clips

          
          
          

          

        

        
Every clip can have several texts. Open Position, size and lines under a text to put it above, below, at the top or bottom of the screen, move it, resize it, or set how many lines it takes. Long batches use phone memory, so save clips as they finish.
